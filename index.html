    About DSS and the DM-1

    SP mode uses the DSS SP codec (about 11 kHz, sound up to ~5 kHz). LP uses G.723.1, a telephone codec (8 kHz, up to ~3.5 kHz). The file header stores the device name and the recording's start time, which the naming pattern uses. Newer DS2 files (DSS Pro) are not supported.
